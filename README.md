## 📌 Project Overview

This Capstone Project focuses on transforming raw business data into meaningful insights using **Microsoft Power BI**. The dashboard provides interactive visualizations, KPI tracking, trend analysis, and business intelligence reporting to support data-driven decision-making.

The project demonstrates skills in:

- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Calculations
- Dashboard Design
- Business Analytics
- Data Visualization

---

## 🎯 Project Objectives

- Analyze business performance using key metrics.
- Identify trends and patterns in the data.
- Build interactive dashboards for stakeholders.
- Generate actionable insights through visualization.
- Improve decision-making with data storytelling.

## 🧮 DAX Measures Used

Examples:

```DAX
Total Sales =
SUM(Sales[Sales Amount])

Average Revenue =
AVERAGE(Sales[Revenue])

Profit Margin =
DIVIDE(
    SUM(Sales[Profit]),
    SUM(Sales[Revenue]),
    0
)
```
